# 敵スキル演出（予告＋サメ）設計メモ

- 日付：2026-11-22
- 規模：小（パイロット。残り8種は絵ができ次第、同じ流れで追加）

## 目的
敵スキルが「いきなり効果だけ起きる」状態なので、何が起きたかプレイヤーにわかり、見て面白い演出にする。凝った演出はせず、シンプルだけど面白い動きにする（ユーザー方針）。

## 決まったこと（ユーザー）
- 全技共通で「予告」：技が出る直前に、HUD の敵の顔の横で技アイコン（既存の EnemySkills01 の10種）がポンと弾んで出て消える
- 技ごとの演出はキャラクターのイラスト（ChatGPT で作成、Enemys01.png のタッチに合わせる）を動かす
- まずサメで作って手触りを確かめる

## 演出仕様
### 予告
- 周期発動型：発動の 0.5 秒前に1回。常時効果型：ステージ開始時（技が付いた時）に1回
- 敵の顔の右横に、顔の0.8倍の大きさで表示。0 → 1.3倍 → 1倍に弾んで出て（0.25秒）、0.35秒止まり、縮みながら消える（0.2秒）

### サメ（ぷよ1個あたり約1秒）
1. 狙ったぷよと同じ高さで、盤面の左外から口を閉じたサメが泳いでくる（0.35秒）
2. 口がぷよに届いたら「口を開けた絵」に切り替え（0.08秒）→「口を閉じた絵」に戻してパクッ。ぷよは口の位置へ吸い込まれながら縮んで消える（0.12秒）
3. サメはそのまま右へ泳ぎ抜けて消える（0.35秒）
4. 敵 HP の横に緑の「+N」が浮かんで消える
- サメの長さはぷよ約2.5個分。盤面の外まではみ出してよい。ぷよより手前に描く
- Lv で複数食べるときは、食べるぷよごとに1匹ずつ順番に
- ゲームは止めない。狙ったぷよが到着前に消えていたら素通りする

## 作り方（Claude の判断）
- **ゲームロジックと見た目の分離**：スキル → `GameContext.ShowEnemySkillWarning`（新規コールバック）→ `GameMainController` → HUD、という既存の `ReduceTime` と同じ注入パターン
- **サメ演出は Prefab を作らずコードで生成**（SpriteRenderer を実行時に作る）。絵は `EnemySkillAssets` に `_sharkOpenSprite` / `_sharkClosedSprite` を追加して持たせる
- **ぷよの取り外し**：`PuyoBoard` に「盤面からぷよを外して返す」メソッドを追加し、消える動きはサメ演出側で行う
- **回復表示**：`EnemyController` に回復イベントを追加し、HUD が HP 数値のテキストを複製して緑の「+N」を出す
- **予告アイコンも HUD がコードで生成**（Prefab 変更なし）
- **2枚の絵の位置合わせ**：取り込み時に、口を閉じた絵を口を開けた絵の体の位置に合わせて平行移動した画像にする
- 画像の置き場所：`Assets/Textures/GameMain/EnemySkills/`

## 非ゴール
- サメ以外8種の技ごとの演出（絵待ち）
- 効果音（後で入れる）
